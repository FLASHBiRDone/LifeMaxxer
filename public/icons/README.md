# App icons

Place the following PNG files here before first production build:

- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- `icon-maskable-512.png` (512×512, safe-zone padding for Android maskable)
- `apple-touch-icon.png` (180×180)

Design notes:
- Dark background (`#10131a`) to match the app's default theme.
- Minimal glyph, no text. An ADHD user will glance at this on a home screen.
- Exported from `/design/icon.svg` (not committed until Casper approves a design).
